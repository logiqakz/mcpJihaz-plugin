# mcpJihaz для веб-агента

Пакет подключает другого агента к работающему облачному JIHAZ и содержит все 13 скиллов, их справочники, правила, рецепты и фирменный логотип. Локальный сервер, Node.js, Firebase Admin и исходники JIHAZ получателю не нужны. Интернет и аккаунт JIHAZ нужны.

## ChatGPT

В ChatGPT раздел **Plugins** принимает архивы, а MCP-сервер подключается отдельно как **приложение** (Apps). Плагин, который объявляет MCP в `mcp.json` (этот архив объявляет), ChatGPT помечает **Desktop only** и в вебе не запускает — так устроен ChatGPT с сентября 2026, а не наш пакет.

Что работает сегодня:

- **Business, Enterprise, Edu.** Админ пространства включает Developer mode (Settings → Apps → Advanced settings), создаёт приложение в **Settings → Apps → Create** с адресом MCP из следующего раздела, проверяет его и публикует на пространство (Workspace settings → Apps → Drafts → Publish). Скиллы админ загружает через Admin → Plugins → Upload plugin или импортирует маркетплейс `logiqakz/mcpJihaz-plugin` (Workspace settings → Plugins → Add → Import marketplace).
- **Pro.** Settings → Apps → Advanced settings → Developer mode, затем Apps → Create с тем же адресом. Работает только чтение и расчёт: пишущие инструменты на Pro недоступны по правилам ChatGPT.
- **Free, Plus, Go.** Свой MCP не подключается. Ждите публикации JIHAZ в каталоге OpenAI.

При первом вызове инструмента войдите своим аккаунтом JIHAZ. Правила и скиллы сервер отдаёт через `get_agent_kit`, архив для этого не нужен.

## Установка в Codex Desktop с GitHub

В версии Codex с поддержкой маркетплейсов добавьте источник `logiqakz/mcpJihaz-plugin` через **Plugins → Add marketplace** или команду `codex plugin marketplace add logiqakz/mcpJihaz-plugin`. Затем установите `mcp-jihaz@jihaz-public` в разделе Plugins и войдите в JIHAZ при первом вызове. Если установленная версия Codex не знает команду `codex plugin`, обновите приложение или используйте ручное подключение MCP ниже.

## Подключение в веб-среде

1. Распакуйте архив. В настройках агента добавьте удалённый MCP-сервер с именем `mcpJihaz` и адресом:

   `https://jihaz-mcp-361817417980.us-central1.run.app/mcp`

2. Выберите Streamable HTTP и OAuth. Войдите через Google аккаунтом, которым пользуетесь в JIHAZ. Права определяются этим аккаунтом. Собственный client secret не нужен: сервер поддерживает динамическую регистрацию клиента и PKCE S256.
3. Если среда принимает плагины, импортируйте папку `mcp-jihaz` или ZIP в поддерживаемом ею формате. Внутри есть переносимый `plugin.json`, `mcp.json` и манифесты совместимости Codex и Claude. Если плагины не поддерживаются, импортируйте `skills/` средствами вашей среды, а `AGENTS.md` добавьте в инструкции агента. Сохраните `references/`, `rules/`, `recipes/` и `knowledge/` рядом с навыками.
4. Дайте агенту инструкцию: «Прочитай AGENTS.md из пакета mcpJihaz. Вызови get_agent_kit без path и сверь версию. Затем прочитай rules/cloud-quickstart.md через get_agent_kit. Покажи доступные мне проекты JIHAZ».

Установка навыков и подключение MCP — отдельные возможности клиента. Один только URL не устанавливает локальные скиллы. Веб-среде без импорта файлов передайте эту стартовую инструкцию: «Перед работой с JIHAZ вызови get_agent_kit без path, затем читай нужный skills/<имя>/SKILL.md и его справочники через этот инструмент». Сервер отдаёт тот же набор без загрузки ZIP.

## Клиенты с конфигурацией

- Общая конфигурация HTTP MCP находится в `.mcp.json`; объедините её раздел `mcpServers` с существующими настройками, сохранив другие подключения.
- Для Codex есть фрагмент `config/codex.toml`. Добавьте его в конфигурацию клиента, затем выполните `codex mcp login mcpJihaz`. Навыки установите отдельно через плагин или поддерживаемую клиентом папку skills.
- Для Claude Code распакованный плагин можно загрузить командой `claude --plugin-dir /absolute/path/mcp-jihaz`. Авторизацию подключённого MCP завершите в клиенте.

Названия экранов и поддержка импорта зависят от агента. Клиент должен поддерживать удалённый MCP Streamable HTTP и OAuth с PKCE; архив не добавляет эти возможности клиенту, у которого их нет.

## Что внутри

`lab-build`, `lab-copy`, `lab-nodes`, `ergonomics`, `kids-sizing`, `shop-rules`, `knowledge-source`, `session-retro`, `client`, `decor-pick`, `money`, `portfolio`, `project-health`.

В `PACKAGE.json` указаны версия плагина, версия набора скиллов, полный список навыков и SHA-256 файлов. `assets/logo.png` и `assets/icon.png` — фирменный знак JIHAZ. Справочники из `knowledge/` продублированы под исходными путями `docs/`, которые встречаются в скиллах. Настольные шаги явно отмечены в облачных редакциях скиллов; для веба используйте `generate_furniture`, `get_lab_session` и остальные доступные инструменты сервера.

Сервер может обновиться после выпуска архива. Перед работой сверяйте версию через `get_agent_kit`; актуальные инструкции получайте там же. Пакет не содержит ключей, токенов, личной памяти или выгрузок заказов. Авторизация получателя выполняется отдельно.

## Пересборка из репозитория JIHAZ.WORK

После изменения исходных навыков обновите их облачные редакции:

```sh
npx tsx scripts/render-claude-skills.ts
npm run package:mcp-jihaz
```

ZIP и контрольная сумма появятся в `dist/`. Упаковщик проверяет актуальность скиллов и содержимое готового архива. Версия набора скиллов берётся из `agent-kit/manifest.json`; версия релиза плагина задаётся отдельно в упаковщике и повышается при обновлении карточки или ресурсов.
